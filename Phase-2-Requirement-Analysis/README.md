# Phase 2: Requirement Analysis
- **Tools Needed:** Python, FastAPI, Uvicorn, Google Gemini API, HTML, CSS, Jinja2, SQLite.
- **Functional Requirements:** Enter user profile (name, ID, age, weight, goal, intensity), generate a personalized workout plan, stream the plan live, generate a nutrition tip, submit feedback to update the plan, view all users and their plans.
- **Non-Functional Requirements:** Fast streaming response, clean and modern UI, secure API key handling using a `.env` file, modular and maintainable code, cross-browser compatibility.
